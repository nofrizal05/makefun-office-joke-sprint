A one-line office joke for make.fun's "One-Line Office Joke: 24-Hour Sprint" bounty — the sort of line you send a colleague after a meeting that should have been an email. One short, original joke about office life, judged pairwise by an AI judge against the other entries.

## Run it

```sh
python3 main.py
```

This writes the joke to `/output/entry.txt` (UTF-8, one line, under 200 characters).
